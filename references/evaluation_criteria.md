# 试题质量评估标准（10 分制）

## 内容效度（默认权重 25%）

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 考点覆盖率 ≥ 90%，认知层级 ≥ 5 层，高阶（分析+评价+创造）占比 ≥ 20% |
| 7-8 | 考点覆盖率 ≥ 75%，认知层级 ≥ 4 层，高阶占比 ≥ 10% |
| 5-6 | 考点覆盖率 ≥ 60%，认知层级 ≥ 2 层（仅记忆+理解） |
| 3-4 | 考点覆盖率 < 60%，或明显偏离教学大纲 |
| 1-2 | 考点覆盖率 < 30%，或与教学内容无关 |

### 内容一致性

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 答案与题干 100% 逻辑匹配，选项主题高度一致，知识点标签准确率 ≥ 90% |
| 7-8 | 答案与题干基本逻辑匹配，知识点标签准确率 ≥ 70% |
| 5-6 | 存在 1-2 处答案与题干不匹配 |
| 3-4 | 存在多处答案与题干不匹配 |
| 1-2 | 大量题目答非所问 |

## 结构效度（默认权重 20%）

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 各选项占比 20%-30%，干扰项有效（≥2个干扰项有明显区分力），最长选项偏差 < 30% |
| 7-8 | 各选项占比 15%-35%，至少1个干扰项有效，最长选项偏差 < 45% |
| 5-6 | 某选项占比 < 15% 或 > 35%，或最长选项偏差 > 45% |
| 3-4 | 某选项占比 < 10% 或 > 40%，多数干扰项无效 |
| 1-2 | 答案分布极度失衡（某选项 > 50%），或选项设计存在明显暗示 |

## 难度控制（默认权重 20%）

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 低:中:高 ≈ 25%-35%:45%-55%:15%-25%，难度呈阶梯式递增 |
| 7-8 | 低:中:高 ≈ 20%-40%:40%-60%:10%-25%（任一档偏离 ≤10%） |
| 5-6 | 低:中:高比例有偏离但基本可接受（任一档偏离 ≤20%）|
| 3-4 | 低难度 > 60% 或高难度 < 5%，难度梯度断裂 |
| 1-2 | 全部题目为同一难度级别 |

## 区分度潜力（默认权重 15%）

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 每道题有明确区分意图（≥80%题目能在不同水平学生间产生得分差异），干扰项区分有效 |
| 7-8 | 大部分题有区分意图（≥60%），干扰项基本有效 |
| 5-6 | 区分意图不足（40%-60%题目为纯记忆型），部分干扰项无效 |
| 3-4 | 多数题为送分题（> 60%为纯记忆型），缺乏区分力 |
| 1-2 | 全部题目无区分度（100%为纯记忆型或难度完全一致） |

## 规范性（默认权重 20%）

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 格式100%统一，题干0歧义，≥90%题目有完整解析（含正确答案+干扰项排除理由），0重复题 |
| 7-8 | 格式基本统一（≥90%一致），题干基本清晰（歧义率<5%），≥70%题目有解析 |
| 5-6 | 格式有少量不一致（≥70%一致），题干歧义率 5%-15%，≥50%题目有解析 |
| 3-4 | 格式混乱（<70%一致），题干歧义率 >15%，<50%题目有解析 |
| 1-2 | 格式极度混乱，大量歧义（>30%），无解析 |

### 语言文字质量

| 分数 | 标准（量化阈值） |
|---|---|
| 9-10 | 通顺度 ≥ 95%，0 错别字，标点规范率 ≥ 98%，0 歧义表述 |
| 7-8 | 通顺度 ≥ 85%，错别字 ≤ 2 处，标点规范率 ≥ 90% |
| 5-6 | 通顺度 ≥ 70%，错别字 ≤ 5 处 |
| 3-4 | 通顺度 < 70%，存在多处语病 |
| 1-2 | 存在大量错别字或严重语病，影响理解 |

## 跨题一致性

跨题一致性是附加校验机制，用于检测试卷中不同题目之间的逻辑冲突：

- **矛盾检测**：两题标准答案存在明显逻辑矛盾时，每题扣 1-2 分
- **知识点一致性**：重复考查同一知识点但答案不一致时，标记为"答案冲突"
- **依赖一致性**：题目间存在条件依赖但逻辑不成立时，标记为"逻辑断裂"

## 评分注意事项

- **考点覆盖率** = Agent 识别的知识点数 / 教学大纲预期知识点数（未知时用 `knowledge_points_summary` 中知识点数量估算）
- **认知层级** 按 Bloom 六层分类（记忆/理解/应用/分析/评价/创造）
- **最长选项偏差** = (最长选项字符数 - 平均选项字符数) / 平均选项字符数
- **干扰项有效性** = 是否能区分"掌握"和"未掌握"的学生（由 Agent 根据选项设计逻辑判断）
- **格式一致率** = 格式统一的题目数 / 总题数
