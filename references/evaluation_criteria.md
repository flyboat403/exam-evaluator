# 试题质量评估标准（10 分制）

## 内容效度（25%）

| 分数 | 标准 |
|---|---|
| 9-10 | 考点全面覆盖教学大纲，认知层级分布合理（记忆≤40%，高阶≥20%） |
| 7-8 | 考点覆盖较全面，认知层级分布基本合理 |
| 5-6 | 考点覆盖基本完整，但认知层级单一（≤2层） |
| 3-4 | 考点覆盖不足，或严重偏离教学大纲 |
| 1-2 | 考点严重缺失，或与教学内容无关 |

## 结构效度（20%）

| 分数 | 标准 |
|---|---|
| 9-10 | 答案分布均衡（各选项20-30%），干扰项质量高，最长选项偏差<30% |
| 7-8 | 答案分布基本均衡，干扰项基本有效 |
| 5-6 | 答案分布有偏差，部分干扰项无效 |
| 3-4 | 答案分布严重失衡（某选项<10%或>40%） |
| 1-2 | 答案分布极度失衡，或存在明显暗示 |

## 难度控制（20%）

| 分数 | 标准 |
|---|---|
| 9-10 | 低:中:高 ≈ 3:5:2，难度梯度合理 |
| 7-8 | 难度比例基本合理，梯度基本清晰 |
| 5-6 | 难度比例有偏差，但基本可接受 |
| 3-4 | 难度比例严重失衡（低>60%或高<5%） |
| 1-2 | 全部为同一难度级别 |

## 区分度潜力（15%）

| 分数 | 标准 |
|---|---|
| 9-10 | 每道题有明确区分意图，干扰项有效区分不同水平学生 |
| 7-8 | 大部分题目有区分意图，干扰项基本有效 |
| 5-6 | 部分题目区分意图不明确 |
| 3-4 | 多数题目为"送分题"，缺乏区分力 |
| 1-2 | 完全无区分度 |

## 规范性（20%）

| 分数 | 标准 |
|---|---|
| 9-10 | 格式统一，题干清晰无歧义，解析完整，无重复题目 |
| 7-8 | 格式基本统一，题干基本清晰，有解析 |
| 5-6 | 格式有少量不一致，部分题干有歧义，部分题目无解析 |
| 3-4 | 格式混乱，题干歧义较多，多数题目无解析 |
| 1-2 | 格式极度混乱，大量歧义，无解析 |
