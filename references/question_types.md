# 题型分类参考

## 客观题

| 题型 | 特点 | 评分方式 |
|---|---|---|
| 选择题 | 提供多个选项，只有一个或多个正确答案 | 标准答案匹配 |
| 判断题 | 判断陈述正确或错误 | 标准答案匹配 |
| 填空题 | 填写关键词或数值 | 标准答案匹配（需考虑同义词） |

## 主观题

| 题型 | 特点 | 评分方式 |
|---|---|---|
| 简答题 | 简要回答核心要点 | 要点匹配 |
| 论述题 | 展开论述，要求逻辑清晰 | 评分标准（rubric） |
| 案例分析题 | 基于具体情境分析 | 评分标准（rubric） |
| 计算题 | 数值计算，要求过程 | 步骤分+结果分 |
| 应用题 | 将知识应用于实际情境 | 评分标准（rubric） |
