# Bloom 认知层级分类

## 六个层级

| 层级 | 描述 | 典型动词 |
|---|---|---|
| 记忆 | 回忆事实和基本概念 | 定义、列出、命名、回忆 |
| 理解 | 解释想法或概念 | 描述、解释、总结、分类 |
| 应用 | 在新情境中使用信息 | 解决、使用、演示、计算 |
| 分析 | 绘制概念间关系 | 比较、对比、区分、组织 |
| 评价 | 证明立场或决定 | 判断、批评、辩护、评估 |
| 创造 | 产生新或原创作品 | 设计、构建、计划、发明 |

## 命题建议

- 记忆类题目 ≤ 40%
- 理解+应用类题目 ≥ 40%
- 分析+评价+创造类题目 ≥ 10%
